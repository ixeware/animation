# animation

Производство коротких анимационных роликов в стиле TikTok-аккаунта **@chess.history**
(истории из истории шахмат: плоская 2D-анимация, полу-3D доска, драматичный голос).

| Файл | Что внутри |
|---|---|
| `STYLE_BIBLE.md` | Полный разбор стиля: структура сторителлинга, правила текста, палитра, персонажи, HUD доски, типографика, камера и переходы, голос, музыка, SFX, темп |
| `reference/episodes.md` | Покадровые разборы всех 4 роликов аккаунта с таймингами голоса, картинки и звуковых ударов |
| `templates/episode_template.md` | Шаблон нового эпизода: паспорт, сценарий по тактам, раскадровка, карточка звука, чек-лист |
| `tools/analyze_tiktok.sh`, `tools/analyze_audio.py` | Пайплайн анализа: скачивание, кадры, склейки, whisper, demucs, поиск ударов |

Сами видео в репозиторий не кладутся: это чужой контент, они нужны только для анализа и
скачиваются инструментом заново.
