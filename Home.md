# Шахматные шортсы

Главная страница хранилища Obsidian. Хранилище — сам репозиторий: заметка, поправленная здесь и отправленная в GitHub,
попадает к Claude в следующей сессии. Ссылки обычные Markdown, поэтому работают и в Obsidian, и на GitHub.

## Главное

- [Входящие](Inbox.md) — новые пожелания и заметки для Claude.
- [Память Claude](memory/README.md) — предпочтения автора, эдит-байты, референсы, спонсоры, журнал: Claude пишет сюда сам после каждого пожелания.
- [STYLE_BIBLE](STYLE_BIBLE.md) — правила стиля 1–67 (раздел 6) и эффекты ходов (§8).
- [Эталон: Rausis v2](reference/rausis_v2.md) — раскадровка лучшего ролика: хук, переходы, камера (правило 45).
- [Эталон качества: Миттенс](reference/mittens/00_overview.jpg) — кадры ролика про Миттенс и его [плашки](reference/mittens/01_plates.jpg): светлые наборы, фигуры на переднем плане, плоские плашки (правила 50, 52).
- [IDEAS](IDEAS.md) — идеи следующих роликов с проверенными фактами, что показали комментарии.
- [CLAUDE](CLAUDE.md) — как собирается ролик, по шагам.
- [HANDOFF](HANDOFF.md) — передача проекта другой модели: окружение, состояние, подводные камни.
- [Медиакит](business/The64Files_media_kit.pdf) — для спонсоров (PDF; страница — `business/media_kit.html`): охват, аудитория, форматы, по аналитике TikTok за 12.10–8.11.2026.
- [Канал-копия на YouTube](business/youtube_copies.md) — что скопировано, ссылки для жалоб, доказательства авторства (13.11.2026).
- [README](README.md) — устройство проекта и строка сборки каждого ролика.
- [Шаблон эпизода](templates/episode_template.md)
