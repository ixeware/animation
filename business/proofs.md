# Отпечатки готовых роликов до публикации

Каждая строка записана `python3 tools/proof.py <файл>` и запушена до публикации ролика: время пуша на GitHub
показывает, что этот файл существовал раньше любой копии (STYLE_BIBLE, правило 70). Проверка: `sha256sum <файл>`.
