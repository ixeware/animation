# Дубли голоса `witty2` (версия 5)

Ответы ElevenLabs (Callum, `eleven_v3`) для каждой фразы `script.json` в том виде, как их кэширует `audio/tts.py`:
звук и метки символов. Лежат в репозитории, потому что `build/` в git не попадает, а подобранные дубли (те, что
кончаются тишиной) заново не получить: без этих файлов озвучку ролика пришлось бы записывать и проверять снова.
Записаны 12–13.11.2026 на бесплатном тарифе ElevenLabs.

Восстановить кэш в новой сессии (кредиты не тратятся, пока текст и поле `voice` в `script.json` не менялись):

    mkdir -p episodes/witty2/build/tts_cache && cp episodes/witty2/voice/el_*.json episodes/witty2/build/tts_cache/
    python3 audio/tts.py episodes/witty2

Имя файла — хэш настроек голоса, текста фразы и номера дубля (`"take"`), так что изменённая фраза в кэше не найдётся.
